



## Observations
- Inspite of using a valid Coupon Code, the expected discount rate 25% is not applied. A flat raot of £0.25 is applied.
- When an invalid coupon code is applied there is no specific error message to the user explaining the coupon is not applied and there will be no discount. This is misleading.
- The coupon success toast message appears as many times as apply button is clicked, rather than once when the actual coupon is applied. This might result in bad user experience.
